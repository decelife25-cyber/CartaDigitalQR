# Erudus icon presentation rules

Source: Erudus branding guidelines, `erudus-brand-guidelines.pdf`.

Relevant rules recorded for CartaDigitalQR:

- Icons must remain legible to the end user.
- Minimum displayed size: 50 px × 50 px.
- Keep at least 10% white space between icons shown together.
- Scale icons proportionally.
- The icon artwork and its colours should not be changed; only the size may be altered.
- Erudus uses colour as a visual cue: red = contains, amber = may contain, grey = does not contain.

Therefore CartaDigitalQR must not recolour or redraw the Erudus artwork merely for visual styling. Any use of the Erudus set should preserve the official artwork and colour semantics.
