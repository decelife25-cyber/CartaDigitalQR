## Resultado de la obtención
La página oficial de Makro (`https://www.makro.es/info-y-servicios/calidad-y-seguridad/alergenos`) devuelve un código de error HTTP 403 (Forbidden) protegido por un sistema de seguridad tipo WAF (Web Application Firewall) o Anti-Bot de Akamai ("ARE YOU LOST? Sorry, only our team of experts has access here") cuando se accede de forma automatizada estándar.

Usando cabeceras personalizadas de un navegador real (`User-Agent`, `Accept`, `Sec-Fetch-*`), se ha podido evadir el WAF y descargar el HTML original de la página.
