# PANTALLA 007 · HOME PRIVADO

# Objetivo

Esta es la pantalla principal de trabajo del restaurante.

No está diseñada para clientes.

Está diseñada para que un camarero o el encargado pueda trabajar durante todo el servicio utilizando únicamente el teléfono móvil.

La prioridad absoluta es la velocidad.

Todo debe poder hacerse con el mínimo número de pulsaciones.

---

# Imagen oficial de referencia

docs/REFERENCIAS/PRIVADO/7_HomePrivado.png

Esta imagen constituye la especificación oficial.

No es una inspiración.

No está permitido reinterpretarla.

No modificar la distribución.

No modernizar el diseño.

Debe reproducirse prácticamente igual.

---

# Filosofía

Esta aplicación no pretende ser un panel de administración genérico.

No es un CMS.

No es un ERP.

Es una herramienta de trabajo diario para un restaurante.

Debe ser extremadamente rápida.

---

# Fuente de datos

Toda la información procede exclusivamente de Supabase.

Nunca utilizar datos mock.

Nunca utilizar datos de ejemplo.

Nunca utilizar JSON locales.

---

# Distribución

Pantalla completa.

Sin menús complejos.

Sin ventanas flotantes.

Sin paneles laterales.

Todo el contenido debe ser visible desde el primer momento.

---

# Cabecera

Debe mostrar:

Nombre del restaurante.

Estado de sincronización.

Botón de configuración.

---

# Botones principales

La pantalla debe mostrar únicamente accesos grandes a:

Familias.

Productos.

Alérgenos.

Sugerencias.

Configuración.

Cada botón debe ser grande.

Muy fácil de pulsar.

---

# Navegación

Cada botón abre directamente su pantalla.

Nunca debe haber pantallas intermedias.

---

# Diseño

Seguir exactamente la referencia.

Máxima cantidad de información.

Mínimo scroll.

La información tiene prioridad absoluta sobre la decoración.

---

# Responsive

Pensado exclusivamente para móviles Android.

Debe poder utilizarse cómodamente con una sola mano.

---

# Rendimiento

La carga inicial debe ser inmediata.

La navegación entre pantallas debe ser prácticamente instantánea.

---

# Prohibiciones

No utilizar plantillas de administración.

No utilizar dashboards comerciales.

No utilizar barras laterales.

No reinterpretar la interfaz.

No crear elementos nuevos.

La imagen oficial define completamente el diseño.

---

# Criterios de aceptación

La pantalla solo se considerará terminada cuando visualmente sea prácticamente idéntica a la referencia y permita acceder rápidamente a todas las funciones principales del panel privado.
