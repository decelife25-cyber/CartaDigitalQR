# PANTALLA 002 · FAMILIAS

# Objetivo

Mostrar todas las familias disponibles de la carta para que el cliente pueda acceder rápidamente a los productos.

Esta pantalla debe ser extremadamente rápida, limpia y totalmente optimizada para móvil.

---

# Imagen oficial de referencia

docs/REFERENCIAS/PUBLICO/2_Familias.png

Esta imagen es la referencia OFICIAL.

No está permitido reinterpretar el diseño.

El resultado debe ser prácticamente idéntico.

---

# Fuente de datos

Supabase.

No se utilizarán datos de ejemplo.

No se utilizarán arrays mock.

No se utilizarán datos hardcodeados.

Todas las familias provienen de la base de datos.

---

# Diseño

Cada familia aparece como una tarjeta.

Cada tarjeta contiene:

- Fotografía.
- Nombre.
- Número de productos (opcional).
- Flecha o indicador de acceso.

Las tarjetas tienen:

- esquinas redondeadas
- sombra ligera
- separación uniforme
- ocupan prácticamente todo el ancho

---

# Comportamiento

Al pulsar una familia:

abrir inmediatamente la lista de productos de dicha familia.

No existen pantallas intermedias.

---

# Scroll

Scroll vertical.

Suave.

Sin saltos.

---

# Fotografías

Si existe fotografía:

mostrarla.

Si no existe:

mostrar imagen placeholder.

Nunca dejar espacios vacíos.

---

# Tipografía

Muy grande.

Muy legible.

Pensada para clientes de cualquier edad.

---

# Colores

Seguir exactamente la imagen oficial.

No inventar colores.

No rediseñar.

---

# Responsive

Diseñado exclusivamente para móvil.

No optimizar primero para escritorio.

El móvil es el dispositivo principal.

---

# Rendimiento

Carga inmediata.

No cargar información innecesaria.

Solo cargar las familias.

---

# Prohibiciones

No añadir botones nuevos.

No añadir banners.

No añadir efectos.

No añadir animaciones innecesarias.

No cambiar la distribución.

No reinterpretar el diseño.
