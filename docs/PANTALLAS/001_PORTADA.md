# 001 - PORTADA (Pantalla principal pública)

## Objetivo

Esta es la primera pantalla que ve el cliente al escanear el código QR.

Debe transmitir una imagen Premium, moderna y elegante, pero con una navegación extremadamente sencilla.

No debe parecer una web tradicional.

Debe parecer una aplicación móvil.

---

# Referencia visual

La implementación debe seguir FIELMENTE la imagen de referencia almacenada en:

docs/REFERENCIAS/PUBLICO/1_Portada.png

No se permite reinterpretar el diseño.

La imagen es la especificación oficial.

---

# Cabecera

En la parte superior debe aparecer:

- Botón Menú.
- Nombre del restaurante.
- Aspecto limpio.
- Fondo oscuro.

---

# Hero principal

Debe existir una tarjeta principal con:

- Logotipo del restaurante.
- Nombre completo.
- Texto de bienvenida.
- Imagen de fondo elegante.
- Bordes redondeados.
- Sombras suaves.

El aspecto debe ser prácticamente idéntico a la referencia.

---

# Acciones principales

La portada debe mostrar accesos directos a:

- Familias
- Buscar plato
- Mi selección

Estos accesos deben ser grandes y fáciles de pulsar.

---

# Diseño

Modo oscuro.

Colores dorados.

Negros.

Grises suaves.

Bordes redondeados.

Espaciados amplios.

Tipografía moderna.

---

# Responsive

La pantalla está diseñada EXCLUSIVAMENTE para móviles.

No debe diseñarse pensando en escritorio.

Toda la interfaz debe ocupar correctamente el ancho de un teléfono.

---

# Navegación

Desde esta pantalla el usuario podrá acceder a:

- Familias
- Buscador
- Mi selección

Nunca aparecerán opciones de administración.

---

# Datos

Toda la información debe proceder exclusivamente de Supabase.

Queda prohibido:

- mockData
- datos de ejemplo
- JSON locales
- arrays temporales

Supabase es la única fuente de datos.

---

# Rendimiento

La pantalla debe cargar en menos de un segundo en condiciones normales.

No cargar imágenes innecesarias.

No realizar consultas duplicadas.

---

# Criterios de aceptación

Se considerará terminada únicamente si:

- Visualmente es prácticamente igual a la imagen de referencia.
- Funciona correctamente en móvil.
- Utiliza únicamente Supabase.
- No contiene datos de ejemplo.
- No modifica el diseño aprobado.
