# PANTALLA 003 · LISTADO DE PLATOS

# Objetivo

Mostrar todos los platos pertenecientes a una familia.

La navegación debe ser extremadamente rápida y pensada para móviles.

El cliente debe poder localizar un plato en pocos segundos.

# Fuente de datos

Supabase.

Todos los platos se cargan desde la base de datos.

Nunca utilizar datos de ejemplo.

Nunca utilizar datos mock.

Nunca hardcodear información.

---

# Diseño

Cada plato aparece dentro de una tarjeta.

Cada tarjeta contiene:

- Fotografía.
- Nombre.
- Descripción corta.
- Precio.
- Indicadores (si existen).
- Flecha para acceder al detalle.

Las tarjetas ocupan casi todo el ancho.

Separación uniforme.

Esquinas redondeadas.

Sombras suaves.

---

# Orden

Mostrar los platos exactamente en el orden definido en la base de datos.

No ordenar automáticamente por nombre.

---

# Fotografías

Mostrar siempre la fotografía.

Si no existe:

mostrar placeholder.

Nunca dejar espacios vacíos.

---

# Precio

Visible.

Grande.

Muy legible.

Siempre alineado.

---

# Nombre

Es el elemento visual más importante.

Debe destacar claramente sobre el resto.

---

# Descripción

Máximo dos líneas.

Si es mayor:

mostrar puntos suspensivos.

---

# Navegación

Al pulsar un plato:

abrir inmediatamente la ficha del producto.

---

# Scroll

Vertical.

Muy fluido.

Sin recargas completas.

---

# Responsive

Diseñado exclusivamente para móvil.

No priorizar escritorio.

---

# Rendimiento

Solo cargar los datos necesarios.

Las imágenes deben cargarse de forma eficiente.

La navegación debe ser inmediata.

---

No añadir filtros.

No añadir animaciones.

No cambiar el aspecto visual.
