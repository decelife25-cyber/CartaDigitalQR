# 05 - PANEL PRIVADO (APP MÓVIL)

## Arquitectura
- Android Nativo + Jetpack Compose.
- Repositorio centralizado para llamadas a Supabase.

## Características
- Autenticación requerida.
- Panel de configuración multirestaurante (cambio de Supabase URL/Key).
- CRUD visual para gestionar la carta (Familias, Productos, Alérgenos).
- No requiere modificar el código fuente para adaptar un nuevo restaurante.
