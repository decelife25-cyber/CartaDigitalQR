# CartaDigitalQR - Manual del Proyecto

## Objetivo
Desarrollar desde cero una carta digital profesional para restaurantes.

## Principios
1. Este repositorio es la única fuente oficial del proyecto.
2. Nunca reutilizar código del proyecto anterior salvo decisión expresa.
3. No crear pantallas por iniciativa propia.
4. Cada pantalla debe seguir fielmente las imágenes de referencia.
5. Prioridad absoluta a móvil.
6. La información es más importante que las fotografías.
7. Las fotos son opcionales y deben admitir placeholders.
8. La única base de datos será Supabase.
9. Nunca usar datos mock salvo autorización expresa.
10. Diseño coherente en toda la aplicación.

## Arquitectura
- App privada independiente instalable (PWA).
- Carta pública conectada a Supabase.
- Mismo modelo de datos.

## Normas para IA
- Antes de implementar, revisar este documento.
- No interpretar requisitos cuando existan imágenes de referencia.
- Si una imagen contradice una decisión estética, prevalece la imagen.
- No introducir mejoras visuales no solicitadas.
- Mantener consistencia en colores, tamaños y espaciados.
- Todo cambio importante debe respetar este documento.

## Filosofía
Primero funcionamiento.
Después fidelidad al diseño.
Después optimización.
Nunca al revés.
