# 019 - REGLAS DE IMPLEMENTACIÓN PARA IA

## Objetivo
Reglas obligatorias para cualquier IA que desarrolle el proyecto.

## Reglas Generales
- Leer todo el directorio `/docs` antes de programar.
- **La documentación es la especificación oficial.**
- Las capturas de pantalla son los criterios de aceptación visual. Nunca rediseñar ni modernizar.

## Restricciones
- Supabase es la **única** fuente de datos.
- Prohibido el uso de `mockData`, arrays locales o datos hardcodeados.
- Código limpio, modular, sin duplicados.
- Hacer comprobaciones de compilación y errores de linting antes de enviar cambios.

## Calidad
No dejar código incompleto ni placeholders `TODO`. La implementación debe coincidir al máximo con la especificación y estar lista para producción.
