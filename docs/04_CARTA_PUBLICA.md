# 04 - CARTA PÚBLICA (PWA)

## Especificación del Manifiesto PWA
El archivo `manifest.json` definirá:
- `name`: Nombre del restaurante.
- `short_name`: "Carta".
- `start_url`: "/".
- `display`: "standalone".
- `background_color`: Color de fondo dinámico.
- `theme_color`: Color principal de la configuración.
- `icons`: Conjunto de iconos (192x192, 512x512).

## Características
- Diseño "Mobile-First" 100% responsivo.
- React + Vite + Tailwind CSS.
- Navegación fluida por categorías de alimentos.
- Visualización de detalles de productos, precios y alérgenos.
