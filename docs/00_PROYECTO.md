# 00 - PROYECTO

## Objetivo General
CartaDigitalQR es un sistema dual que permite a los restaurantes ofrecer su carta en formato digital a través de un código QR (Aplicación Pública PWA), y gestionar todo el contenido desde una aplicación móvil (Aplicación Privada Android) sin necesidad de conocimientos técnicos.

Ambas aplicaciones están respaldadas por una única base de datos Supabase, que actúa como fuente única de verdad.
