# Editor de productos

El panel privado de productos debe funcionar primero en móvil y sin desplazamiento horizontal.

Incluye:
- búsqueda por nombre, descripción y familia;
- filtro por familia;
- filtro por estado: visible, oculto, disponible, agotado y destacado;
- orden por posición, nombre y precio;
- acciones rápidas para visible, disponible y destacado;
- edición completa del producto;
- gestión de familia, precio, descripción, imagen, orden y alérgenos;
- eliminación con confirmación;
- errores de Supabase visibles para el administrador.
